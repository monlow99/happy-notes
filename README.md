# 😊 Happy Notes

¡Bienvenido a **Happy Notes**! Una aplicación de notas minimalista, elegante y diseñada para hacerte sonreír mientras capturas tus ideas más brillantes.

## 🌟 Características

- **Diseño Glassmorphism**: Una interfaz moderna con transparencias y desenfoques elegantes.
- **Organización Visual**: Asigna colores alegres a tus notas.
- **Priorización**: Fija tus notas más importantes arriba.
- **Búsqueda Rápida**: Encuentra cualquier pensamiento en segundos.
- **Persistencia Local**: Tus notas se quedan guardadas en tu navegador.

## 🚀 Instalación y Uso

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/monlow99/happy-notes.git
   cd happy-notes
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Ejecutar en desarrollo**:
   ```bash
   npm run dev
   ```

4. **Acceso**: Abre [http://localhost:5173/](http://localhost:5173/) en tu navegador.

## 🛠️ Tecnologías

- **React 19**
- **Vite 5** (optimizado para Node 18+)
- **Vanilla CSS** con variables y efectos modernos.
